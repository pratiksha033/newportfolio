FCFS

The First Come First Served (FCFS) algorithm processes jobs in the order of their arrival, ensuring simplicity but sometimes causing delays for short jobs.

02

SJF

Shortest Job First (SJF) selects the job with the shortest burst time next. It's efficient but can starve long-running processes.

Read More Demo

03

LRTF

Longest Remaining Time First gives CPU preference to jobs with the most remaining burst, which can be useful for specific workloads.

Read More Demo

04

SRTF

Shortest Remaining Time First preempts currently running jobs if a new job arrives with a shorter remaining duration, helping minimize average waiting time.

Read More Demo

05

Priority Scheduling

Priority Scheduling gives CPU access based on task priority, ensuring important jobs finish sooner, but potentially starving low-priority tasks.
